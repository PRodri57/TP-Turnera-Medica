# Turnera Médica (TP Final Java)

**Turnera Médica** es un proyecto desarrollado en Java como Trabajo Práctico Final, que permite gestionar turnos médicos utilizando una base de datos **H2** embebida.

## 🔍 Características

- Registro y administración de médicos, pacientes y turnos  
- Persistencia usando base de datos **H2** (modo embedded)  
- Lógica de validación (por ejemplo, evitar turnos duplicados)  
- Interfaz (console / básica) para interactuar con el sistema  
- Modularización clara del código en paquetes

---

## 🛠 Tecnologías

- Java (versión según el proyecto)  
- H2 Database (modo embebido)  
- Herramientas de compilación / ejecución (por ejemplo, Maven o Gradle si aplica)  
- (Opcional) Logging, pruebas unitarias, etc.
